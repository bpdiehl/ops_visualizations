# Rights and source provenance

No public reuse license has been selected. Do not describe this project as open source until the owner chooses and adds an appropriate license. The intended delivery is browser files for classmates; decide reuse/modification/redistribution terms before the initial publication.

Suggested owner decision: consider MIT for original code and original teaching text if broad reuse is desired. This is a recommendation, not a license grant. Third-party material keeps its own terms and cannot be relicensed merely by including it here.

The working briefs were derived from the owner's supplied MBA Interactive Learning Lab planning specification v1.0 dated 2026-10-30. The original Markdown and 27-page PDF remain in the private workspace. They describe course anchors but are planning documents. The referenced lecture notes, schedules and cases were not provided in this setup and have not been independently verified.

Keep original PDFs, paid case texts/tables, notes containing personal details, names of classmates and identifiable student data out of the public repository. Use original paraphrases and illustrative numbers. Record a precise public citation and permission/license when an external asset or exact sourced example is used. Do not invent professor quotes or suggest university/faculty endorsement.

See [GitHub's licensing guidance](https://docs.github.com/en/repositories/managing-your-repositorys-settings-and-features/customizing-your-repository/licensing-a-repository) for the difference between a public repository and licensed reuse.
